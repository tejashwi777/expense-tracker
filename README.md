## 🌷 About the project

Pinky Wallet is a cute, pink-themed personal finance tracker designed to make managing money feel simple, fun, and beautiful.

Whether you're tracking your daily spending or saving for something special, Pinky Wallet helps you stay organized.

## ✨ Features

- 💗 Track income and expenses
- 🎀 Calculate your total balance
- 🌸 Categorize transactions
- 📊 Visual spending breakdown
- 💌 Set a monthly budget
- ⭐ Create a savings goal
- 💾 Save data using browser local storage
- 📱 Responsive layout

## 🛠️ Built with

- HTML
- CSS
- JavaScript
- Chart.js

## 🚀 Getting started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/expense-tracker.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No installation required!
